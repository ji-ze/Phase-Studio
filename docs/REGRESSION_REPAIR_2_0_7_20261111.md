# Development regression repair: 11 November 2026

This repair preserves the native scientific algorithms and original legal resources.
Local verification evidence and experimental files remain outside this document.

## Jana protocol boundary

The failing copy was a local copy of the original project context into candidate
staging. A controlled Windows reproduction has an existing source and parent but
a 262-character destination that raises FileNotFoundError. This does not establish
that every missing-file error is a path-length error.

Resolve original project metadata before conversion; do not manufacture an m50
from a predicted CIF. A generated Superflip input can use its canonical original
project context when the corresponding input or reflection-sidecar anchor exists.
Missing or inaccessible metadata produces an actionable local handoff error.
Only genuine remote exceptions retain the remote-server classification.

Long conversion paths use a private short directory and short native filenames.
Python filesystem operations support extended Windows paths. Candidate/run/cycle,
map/CIF/native-model hashes and map-frame validation remain mandatory. Publication,
stale-model removal, final validation, snapshot and evidence archiving share the
rollback boundary. Previous live files and each separate attempt remain evidence.
No paid inference, reflection mutation or new scientific reconstruction is needed.

## Wizard and significance policy

Diagnostics load asynchronously from the selected input snapshot. They open as
visible dialogs owned by the Wizard, without constructing a hidden main window.
Invalid, pending and stale inputs disable the corresponding actions. Closing or
changing the source cancels delivery of an obsolete request.

Valid-input diagnostic no-ops and the reported Next no-op were not reproduced at
the starting development commit. Tests distinguish those observations from the
reproduced stale-enabled-state and modal-ownership defects.

Simple Wizard filtering is always zero and has no threshold control. Advanced
filtering defaults to zero. Precedence is an explicitly saved compatible project
value, a compatible last explicit value, then zero. Save is an explicit action;
restoring or navigating never establishes consent. Reset records explicit zero.
The legacy global default is neither deleted nor treated as consent.

Only measured I/sigma(I) or F/sigma(F) supports a positive native threshold.
FWHM, dummy uncertainty and unknown metadata cannot become measured sigma.
The separately labeled F/[2 sigma(F)] diagnostic is not the native F threshold.
Existing filtering equations, native writers and numerical algorithms are unchanged.

## Count interpretation and restrained layout changes

CIF maxima and the native EDMA-selected Jana model can have different site counts.
The native model is not regenerated, expanded or blocked solely because of count
inequality. UI summaries name both representations. Artifact identity and native
content validation, rather than count equality, determine handoff eligibility.

About retains four compact cards, original branding and independent original-text
readers. The result preview precedes auxiliary controls in its scroll region; the
handoff footer stays reachable. Elided metadata opens an accessible full-text
Details viewer. Reference-free agreement and phase consistency are not independent
structural-accuracy claims. Physical-monitor DPI and interactive Jana refinement
remain separate acceptance gates.
