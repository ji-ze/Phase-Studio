# Upstream license resources

These are separate third-party texts, not relicensed under Phase Studio MIT.

- LGPL-3.0 and GPL-3.0 texts: Qt qtbase v6.11.1 LICENSES directory,
  https://github.com/qt/qtbase/tree/v6.11.1/LICENSES
- GFDL-1.3 text: same upstream directory, for the Qt documentation snapshot.
- Qt third-party notice snapshot (unmodified HTML, GFDL documentation terms):
  https://doc.qt.io/qt-6.11/licenses-used-in-qt.html
- OpenSSL Apache-2.0 text, exact runtime source version 3.5.7:
  https://github.com/openssl/openssl/blob/openssl-3.5.7/LICENSE.txt

Other runtime license files are copied from the exact installed wheel
distributions at build time. Science Gothic's OFL text is in
phase_studio/assets/fonts. See THIRD_PARTY_NOTICES.md for component attribution,
corresponding-source access and replacement/rebuild instructions.
